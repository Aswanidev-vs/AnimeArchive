# AnimeArchive

![AnimeArchive logo](./logo.png)

A premium, private, collaborative anime screenshot archive built with Nuxt 4.

Preserve the moments. Organise the memories. Revisit the frames.

## Stack

- Nuxt 4 (Vue 3 Composition API, TypeScript)
- Tailwind CSS
- Lucide icons (`@lucide/vue`)
- Mock data API layer (ready for Go/Python backend)

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run typecheck` — TypeScript check

## Features

- Home dashboard with featured moment, stats, recent uploads, favourites, collections
- Gallery with masonry/grid/compact views, filters, selection, image viewer
- Anime library and per-anime archive with episode browsing
- Collections (create, edit, delete)
- Favourites and recently added views
- Upload with drag-and-drop, queue, progress, metadata
- Global search (Ctrl/Cmd+K)
- Settings with storage usage
- Dark (default) and light themes
